  • Mandatory cloud dependencies fail during internet connectivity outages.

Backend Implementation

OOP Encapsulation & SQLite Row Factories

The InventoryManager class encapsulates all state and database lifecycles:

  • Self-Healing Schema: _create_tables() runs idempotently upon startup.
  • Named Column Mapping: conn.row_factory = sqlite3.Row allows accessing fields like dictionaries (e.g. product["price"]).
  • Input Sanitization: clean_product_data() standardizes types and raises friendly validation errors.
class InventoryManager:
    def __init__(self, db_path=DB_PATH):
        self.db_path = db_path
        self._create_tables()

    def _connect(self):
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row
        conn.execute("PRAGMA foreign_keys = ON")
        return conn
🗣️ Speaker Note: Highlight that by setting `conn.row_factory = sqlite3.Row`, SQLite query results behave like Python dictionaries, simplifying Jinja2 rendering.
Data Integrity & Oversell Protection

Atomic Transactions & Guard Validation

Every Stock IN or OUT operation runs as a unified atomic transaction:

  • Validates that requested quantity is a positive whole integer.
  • Oversell Guard: If OUT quantity > stock, raise InsufficientStockError.
  • Updates stock count and inserts transaction log atomically.
  • Rolls back completely if any database error occurs.

Data Portability Engine

Fault-Tolerant CSV Import & Export

📥 Fault-Tolerant Bulk Import

  • Decodes standard UTF-8 and UTF-8-BOM (for Microsoft Excel exports).
  • Line-by-line validation: invalid rows are skipped and collected in an error list.
  • Valid rows are saved without corrupting or aborting the rest of the batch.
  • Detailed user flash alert: "Imported 12 products. Line 4: Price cannot be negative."

📤 In-Memory CSV Export

  • Streams catalog data directly from memory via io.StringIO and csv.writer.
  • Zero disk clutter: generated on-the-fly without creating temporary files.
  • Served with Content-Disposition: attachment; filename=inventory.csv.
🗣️ Speaker Note: Emphasize the robustness of the CSV engine: if a storekeeper imports a CSV with 100 products and 1 row is corrupted, the other 99 rows are ingested smoothly.
